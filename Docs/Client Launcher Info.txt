Instructions for the client launcher:

1. Extract CSOLauncher.exe to CSNZ\Bin folder
2. Run CSOLauncher.exe. If you want to connect to another server you can use -ip -port parameters in shortcut. For example: "GamePath\CSOLauncher.exe -ip 192.168.0.2 -port 30002"

Launch parameter list for the client launcher:
1. -debug/-dev/+developer 1/-developer (enable debug console. by default, disabled)
2. -ip <ip> (master server's IP. default: 127.0.0.1)
3. -port <port> (master server's port. default: 30002)
4. -username <username> (username for auto login. by default, disabled)
5. -password <password> (password for auto login. by default, disabled)
5. -useoriginalserver (use IP and port from the NARs/PAKs. by default, disabled)
6. -dumpmetadata (dump metadata packets received to folder "CSNZ\Bin\MetadataDump". by default, disabled)
7. -ignoremetadata (ignore metadata received. by default, disabled)
8. -dumpall (dump all packets received to folder "CSNZ\Bin\Packets". by default, disabled)
9. -disableauthui (disable login/register pop-up. by default, pop-up enabled)
10. -usessl (use ssl when connecting to the master server. by default, not using ssl)
11. -writemetadata (overwrite zip metadatas from the folder "CSNZ\Bin\Metadata". by default, disabled)
12. -loaddedifromfile (load dedicated server csv/json files from the folder "CSNZ\Data". by default, loading from filesystem and hardcoded values)
13. -nonghook (disable the hook of BlackCipher2/NGClient, which makes the anti-cheat be able to run. by default, anti-cheat disabled)
14. -nomutex (don't create mutex, which allows more than one instance of the game to be running at the same time. by default, only one instance is allowed)
